Comseg

Commercial breaks in DVR recordings, found with Comskip and stored as Jellyfin Commercial media segments. Recordings still being written are analysed while they record (this needs the patched Comskip build described in the README); finished recordings get a full pass from the Media Segment Scan.

Path to the comskip binary, or a bare name found on the server's PATH.
A comskip.ini to use instead of the built-in one. The plugin always sets the run-mode keys itself.
Where Comskip writes its files. Empty uses a comseg folder under Jellyfin's data directory.
Run Comskip against each recording as it is written and publish breaks as they are confirmed.
Replace a recording's breaks with a full analysis once it finishes, and analyse recordings the Media Segment Scan finds without breaks.
How often the live Comskip re-runs its full analysis over what it has seen so far. 60 is a good default.
A break must be reported by this many consecutive analyses. 2 drops the one-off false breaks seen on sports feeds.
Comskip waits this many 4 s rounds for a recording that stopped growing before it gives up. 300 is 20 minutes.
Jellyfin's own recording folders are always included.
