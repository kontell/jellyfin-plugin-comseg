Comseg

Commercial breaks in DVR recordings, found with Comskip and stored as Jellyfin Commercial media segments. Recordings still being written are analysed while they record (this needs the patched Comskip build described in the README); finished recordings get a full pass from the Media Segment Scan.

Path to the comskip binary, or a bare name found on the server's PATH.
A comskip.ini on the server to use instead of the built-in one; Check Comskip says which one runs use. The plugin always sets the run-mode keys itself.
Where Comskip writes its files. Empty uses a comseg folder under Jellyfin's data directory.
Run Comskip against each recording as it is written and publish breaks as they are confirmed.
Replace a recording's breaks with a full analysis once it finishes, and analyse recordings the Media Segment Scan finds without breaks.
How much recording passes between the live Comskip's break-finding passes. Each frame is decoded once, as the recording grows; every pass reuses those frames and finds the breaks afresh, which takes seconds. 60 is a good default.
A break must be reported by this many consecutive analyses. 2 drops the one-off false breaks seen on sports feeds.
720 or 480 has Comskip analyse a copy the GPU scales down through VA-API, which costs a fraction of a core where decoding a UHD recording costs Comskip several. Recordings no taller than this are analysed as they are.
The VA-API render device that makes the copy. The user Jellyfin runs as needs access to it.
Comskip waits this many 4 s rounds for a recording that stopped growing before it gives up. 300 is 20 minutes.
Separate several with semicolons. Jellyfin's own recording folders are always included.

Channel profiles

Settings for the recordings of particular channels. A recording's channel is noted from its timer when it starts recording; the first profile that lists it applies, and recordings no profile lists run with the settings above.

Catchup

Let clients, such as the Catchup Download add-on for Kodi, save a finished programme from the M3U provider's catchup archive into the recordings. Users need permission to manage live TV recordings. Works with Flussonic-style archives.
The archive begins at the first segment after the time asked for, up to a segment late.
A download waits while Jellyfin records, has a recording due, or shows live TV, and stops to wait again if one of those starts.
